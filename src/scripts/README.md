# Scripts 目录

此目录包含用于测试和维护项目的实用脚本。

## 可用脚本

### test_dify_connection.py

测试 Dify API 连通性的脚本，用于验证配置是否正确。

#### 使用方法

```bash
# 确保已安装依赖
uv sync

# 从项目根目录运行测试脚本
python src/scripts/test_dify_connection.py
```

#### 测试内容

该脚本会依次测试以下内容：

1. **配置加载验证**
   - 检查 `config.ini` 文件是否存在
   - 验证配置文件格式是否正确

2. **基本网络连通性**
   - 测试能否连接到 Dify API 服务器
   - 验证 Base URL 配置

3. **API 认证**
   - 验证 API Key 是否正确
   - 检查认证权限

4. **工作流执行**
   - 发送测试问题到工作流
   - 验证工作流是否正常响应
   - 检查输出变量配置

5. **工作流映射检查**
   - 显示已配置的工作流映射
   - 验证映射配置

#### 常见问题排查

**❌ 网络连接失败**
- 检查网络连接
- 验证 Base URL 是否正确
- 检查防火墙设置

**❌ API 认证失败 (401)**
- 验证 API Key 是否正确
- 检查 API Key 是否已过期

**❌ API 端点不存在 (404)**
- 检查 Base URL 配置
- 确认 API 版本是否正确

**❌ 请求超时**
- 增加配置文件中的 timeout 值
- 检查 Dify 服务状态

**❌ 未找到预期的输出变量**
- 检查 `output_variable_name` 配置
- 确认工作流实际的输出字段名称

#### 退出代码

- `0`: 所有测试通过
- `1`: 测试失败
- `130`: 用户中断（Ctrl+C）
